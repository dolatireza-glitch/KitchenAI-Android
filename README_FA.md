# نمونه اولیه Kitchen AI — اندروید

این پروژه یک **نمونه اولیه قابل ساخت** برای اپلیکیشن موبایلی طراحی آشپزخانه است. فعلاً شامل این موارد است:
- دریافت عکس با دوربین یا انتخاب از گالری
- ثبت دستی ابعاد پایه
- ثبت و نمایش نشانگرهای تأسیسات روی تصویر
- خروجی طرح/نقشه شماتیک اولیه

## نکته مهم
این نسخه هنوز مدل بینایی ماشین یا API هوش مصنوعی متصل ندارد؛ بنابراین پریز، لوله، درین، پنجره و ابعاد را خودکار تشخیص نمی‌دهد. این قابلیت مرحله بعد است و برای آن به مدل/سرویس AI و روش معتبر اندازه‌گیری نیاز داریم. عکس معمولی به‌تنهایی ابعاد دقیق را تضمین نمی‌کند.

## ساخت و نصب
این پروژه برای Android Studio و Gradle آماده‌سازی شده است، اما برای ساخت APK ممکن است لازم باشد نسخه Android Gradle Plugin و Gradle مطابق نسخه نصب‌شده Android Studio تنظیم شود.
1. پوشه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync انجام شود.
3. گوشی Samsung Galaxy S24 را با USB وصل کنید و USB debugging را فعال کنید.
4. Run را بزنید یا از Build > Build APK(s) خروجی APK بگیرید.

## مسیر توسعه
1. افزودن تشخیص تصویری واقعی و نمایش confidence برای هر تشخیص.
2. تأیید/اصلاح موارد توسط کاربر.
3. افزودن اندازه‌گیری مبتنی بر ARCore یا نقاط مرجع معلوم.
4. افزودن طراحی کابینت سه‌بعدی و محاسبه قیمت.


## ساخت ابری APK (بدون نصب Android Studio روی کامپیوتر)
فایل `.github/workflows/android-apk.yml` یک گردش‌کار GitHub Actions دارد که با اجرای آن می‌تواند نسخه debug را بسازد و به‌عنوان Artifact تحویل دهد.

برای استفاده:
1. باید کل پوشه پروژه در یک مخزن GitHub قرار بگیرد.
2. در GitHub بخش Actions را باز کنید و گردش‌کار `Build Kitchen AI APK` را اجرا کنید (یا با push به شاخه main آن را اجرا کنید).
3. پس از موفقیت، از صفحه اجرای workflow فایل `KitchenAI-debug-apk` را دانلود کنید و APK داخل آن را روی گوشی نصب کنید.

محدودیت‌ها:
- این روش به حساب GitHub و دسترسی به Actions نیاز دارد؛ من از این گفتگو به مخزن تو دسترسی ندارم و آن را خودکار آپلود نکرده‌ام.
- خروجی فعلی فقط نمونه اولیه است؛ AI واقعی، مدل تشخیص تصویر، backend امن، طراحی سه‌بعدی قابل ویرایش و محاسبات کامل قیمت هنوز پیاده‌سازی نشده‌اند.
- APK تولیدشده debug است، برای انتشار عمومی باید نسخه release و امضای امن پیکربندی شود.
